# AI Agent Rules (Frontend)

**Repo:** FixoraF — client-side only. **Tools:** Cursor + Codex (VS Code).

## Always read (in order)

1. `docs/AI_HANDOFF.md` — last agent, next task
2. `docs/TASK_BOARD.md`
3. `docs/DECISIONS.md`
4. `docs/FIXORA-ANALIZ.md` (UI §9, ER §4.9 for types)

## Always update before finishing

1. `docs/AI_HANDOFF.md` — set `Last agent` to `Cursor` or `Codex`
2. `docs/TASK_BOARD.md` — mark completed tasks

Never contradict approved decisions. Never duplicate work marked Done.
